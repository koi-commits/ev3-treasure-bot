# 项目总体方案（EV3 通用寻宝机器人）

> 本文整理自小组原始方案和项目会话。部分方案尚未获得实机验证；以实际测试记录为准。

## 项目目标与约束

- **平台**：LEGO MINDSTORMS EV3，Pybricks 4.1.2，Python / MicroPython。
- **场地**：黑色矩形区域，四周白色边界；终点位置固定，可设置颜色标记与简易接收区域。
- **起点**：场内随机位置与朝向；单个朝下颜色传感器无法解决“光斑已在白线外侧深色区域”这种不可观测初始情形。
- **目标物**：形状、材质、颜色不固定，尺寸不极端。
- **成功条件**：自主寻找目标物、保持运输、送至指定区域并放下。以真实落点而非机器人自报结果判断成功。
- **优先级**：通用性和真实成功率高于运行速度。
- **硬件原则**：保留 EV3 主控、两台驱动电机、原车底盘和颜色传感器；尝试少量拼搭的被动 V 形推板，不优先采用复杂机械臂。

## 核心技术方案

1. 依据实测黑白反射率寻找场地边界。
2. 通过 `CRUISE / ESCAPE / CLEAR` 三状态控制器沿白边行驶。
3. 识别独特的终点色标，停车并建立位置参照。
4. 在未知目标位置下进行覆盖式搜索与被动推送；以负载变化、回撤和重新接触检查作为有限的接触证据。
5. 使用里程计与几何路径规划尝试将物体送至终点，最终由现场目视判断是否成功。

单个朝下传感器无法直接看见车头前方物体；负载变化也不能保证捕获成功。完整寻宝效果必须实机验证。

## 真实硬件基线（2026-11-03）

- 左轮 `Port.A`，右轮 `Port.D`，电机正向均为 `CLOCKWISE`。
- 朝下颜色传感器 `Port.S1`；第一块传感器读数恒定，替换后正常。
- 黑色反射率约 `0.7–1.0`，白色约 `11.2–12`；阈值约 `6.35`。
- 实机确认 `demo_edge.py` 三状态沿边巡线可运行。其他完整任务模块仅经过离线测试。
