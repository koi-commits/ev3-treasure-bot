## 1. 色标模型（2026-11-18 用户确认）

终点色标是**一张方形红纸，压在白色边界线上**（盖住白线的一部分）。纸的边长未知，
先设 `MARKER_SIDE_MM = 150` [TBD - 用尺量纸]；矩阵同时测 100 / 150 / 200 mm。

仿真里的精确模型（`tests/sim.py: rect_arena_marker`，白带宽 40 mm）：

- 选一条边（右/上/左/下）；纸的沿墙中心默认在该边中点；角落场景放在右墙靠上角。
- 白线中心线：右墙 `x = W + 20`，左墙 `x = -20`，上墙 `y = H + 20`，下墙 `y = -20`。
- 纸中心相对白线中心线的**向内偏移** `offset` 在 `[-side/4, +side/4]` 随机；
  这样纸始终盖住整条 40 mm 白带。
- 右墙为例：纸中心 `x = W + 20 - offset`，`y = 沿墙中心`；纸覆盖
  `x ∈ [xc - side/2, xc + side/2]`。`surface_at()` 先查 marker，所以纸下面的白线
  读数变成红色；纸外的白线仍是白色。
- 目标点 = **纸在场内那部分的中心**：沿墙方向取纸中心，横向取"白线内沿（场地边界）
  ↔ 纸内沿"的中点，永不越过白线内沿。场内部分宽度小于 20 mm 时仍取中点，并打印
  `marker inside part narrow`。

## 2. 流程

```
start_check ─► seek_edge ─► edge_probe（定轴向 + 边界）
      ─► 车道扫描（找物体）─► 触碰捕获 + 坐实确认
      ─► 把物体搬到场内中心停好 ─► 贴墙扫描找红纸
      ─► 探针量纸的沿墙范围与内沿 ─► 回捕 ─► deliver（纸的场内部分中心）─► release
```

| 阶段 | 做什么 | 为什么这样做 |
| --- | --- | --- |
| 起步自检 | 光斑若压在白线/红纸上，先倒车再走 | 起点随机，可能贴着边 |
| 寻边 | 直行到见白，倒车，然后开始 | 复用已实机验证的 `seek_edge` |
| 定轴向 | `edge_probe` 撞边采点；直线拟合失败时用 `fit_axis` 按配对聚类 | 起点靠近墙角时，斜撞会分别撞到两条互相垂直的墙，直线拟合必然失败 |
| 扫掠找物 | 车道垂直于起始边，间距 70 mm，逐条推进；见白/红/到墙角/连续三次空扫就换方向 | 覆盖式搜索轮胎；不再先绕场一圈，否则会把场内物体提前顶到墙边 |
| 捕获 | 触碰连续 3 个样本 pressed，然后再前进 400 ms 确认坐实 | 擦碰也会短暂压下挡板；不坐实的捕获送到一半就丢 |
| 停物体 | 捕获后先把轮胎推到**场内中心**，倒车把它留在那里 | 贴墙找纸时不会把停在场边的轮胎顶出界 |
| 找色标 | 空车贴墙扫一圈：垂直撞边、沿墙 100 mm 一步；红纸和白色一样算边界 | 纸盖住白线，必须把红读数当边界；步距 ≤ 纸边长才能保证撞到 |
| 量纸 | 在纸张附近用 25 mm 步距垂直探针，二分找两条沿墙边；红读数起始点给纸内沿 | 扫描只给一个点；交付要的是纸中心和场内部分的中点 |
| 回捕 | 回到停轮胎的位置重新收进 V 口 | 量纸的过程中可能碰到轮胎 |
| 交付 | 先到场内待命点，再沿纸所在边的法向直线推进，让**轮胎中心**落在目标点 | 只走前进弧线；目标永不越过白线内沿 |
| 释放 | 倒 150 mm 停车，打印 `DELIVERED (unverified, check by eye)` | 机器人看不见物体，必须目视判定 |

`MISSION_MODE`：`sweep`（只扫、打印色标估计与车道图）、`capture`（扫到触碰即停）、
`full`（完整任务）。`edge_to_finish` 仍然可用，是已实机验证的老路径，行为未改。

### 3.1 红纸当边界

- `is_boundary(s) = s.white or s.label == FINISH`：红纸和白色一样触发急停、倒车、
  `Boundary.observe` 更新墙的位置。所有扫描/推送阶段都用它，防止从纸下穿过白线
  开到场外。
- `Boundary.observe` 仍按行驶方向判断撞的是哪一族墙；红纸所在的墙面另由扫描时
  "当时正对着的那条墙"（`ctx.scan_wall_k`）确定，避免在角落把纸归到相邻墙。
- 墙线位置用这条墙上的**白色**撞击点的中位数，而不是包围盒极值；斜撞或过冲会让
  极值偏出 10–30 mm，直接影响交付目标。
- 围栏：空车只信已观测到的墙；携带时保留未知墙的短先验。去待命点时沿"目标方向"
  查围栏，避免从纸边起步就误判。

## 5. 已知限制（都要在实机上先确认再谈"能用"）

1. **纸的边长与位置还是 [TBD]**：边长按 150 mm 跑；实机要用尺量，并确认纸与白线的
   相对位置。边长设错会直接影响目标点；100/150/200 的差别见 4.1。
2. **角落场景成功率 1/20**：搜物车道在角落把轮胎顶出场（3/20），且找纸/交付路径
   靠近两条墙。这是当前最弱的一类。
3. **靠边物体 3/20**：轮胎被顶到墙边后，V 口没有从正面收进去的空间。
4. **轮子会压白带**：光斑 20 mm 对半轮距 57 mm 的几何限制；双轮同时出界 4–6/20。
   规则允许轮压白带，只要整车不掉出去。
5. **交付误差中位 15–23 mm**：目标点由探针估计，沿墙误差和里程计漂移都在里面。
   场内最大误差 59.8 mm；纸大（200 mm）时角落最大 61.5 mm。
6. **捕获靠运气**：V 口只有正面吃进才稳定；`seat_ok` 会误杀一些真实捕获。
7. **找纸必须关围栏**：围栏让光斑停在离墙 143 mm，看不到压在墙上的纸；关围栏
   后推板可能压过白带。
8. `OBJ_LEAD_MM`、`GYRO_POSITIVE_DIRECTION`、轮距/轮径仍是 [TBD]。
